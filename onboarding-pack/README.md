# Onboarding Pack

**This folder starts empty on purpose.**

Bob fills it in when you run the Orient tasks. After you run the two core
tasks you should see:

- `SETUP.md` — the real, verified steps to run the sample app (from the
  env-archaeologist task).
- `.env.example` — a complete environment file (from the same task).
- `DOC-CORRECTIONS.md` — every place the sample app's README is wrong
  (from the doc-reconciler task).
- `ARCHITECTURE.md` — a map of the codebase (optional third task).

If this folder is still empty, you haven't run the tasks yet. See the
top-level README and the Playbook PDF.
